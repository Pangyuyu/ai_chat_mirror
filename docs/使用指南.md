# 使用指南

## 快速开始

### 1. 启动项目

```bash
# 在项目根目录
npm run dev
```

这会同时启动前端和后端服务：
- **后端**: http://localhost:3000
- **前端**: http://localhost:5173

### 2. 配置 AI

在左侧面板配置两个 AI：

1. **角色名称**：给 AI 起个名字（如：程序员小明、产品经理小红）
2. **模型选择**：选择要使用的 AI 模型
3. **API Base URL**：API 接口地址（选择模型后会自动填充）
4. **API Key**：你的 API 密钥
5. **系统提示词**：定义 AI 的人设和背景

### 3. 设置话题

在顶部话题输入框中输入对话主题，例如：
- "人工智能的未来发展"
- "程序员 vs 产品经理：需求的博弈"
- "远程办公的利弊"

### 4. 开始对话

点击【开始对话】按钮，两个 AI 就会开始轮流发言。

### 5. 控制对话

- **暂停/继续**：暂时停止或继续对话
- **停止**：结束当前对话
- **重置**：清空对话内容
- **插入发言**：在底部输入框输入你的观点，AI 会基于你的发言继续

### 6. 导出对话

点击右侧【导出为 Markdown】按钮，将对话记录保存为文件。

## API Key 获取

### 通义千问（阿里云）
1. 访问 https://dashscope.console.aliyun.com/
2. 登录/注册阿里云账号
3. 开通 DashScope 服务
4. 创建 API Key

### Kimi（月之暗面）
1. 访问 https://platform.moonshot.cn/
2. 登录/注册账号
3. 在控制台创建 API Key

### 智谱 AI
1. 访问 https://open.bigmodel.cn/
2. 登录/注册账号
3. 在控制台获取 API Key

### 文心一言（百度）
1. 访问 https://cloud.baidu.com/product/wenxinworkshop
2. 登录/注册百度账号
3. 创建应用获取 API Key

## 配置说明

### AI 配置参数

| 参数 | 说明 | 示例 |
|------|------|------|
| 角色名称 | AI 在对话中显示的名字 | 程序员小明 |
| 模型选择 | 选择 AI 提供商 | 通义千问、Kimi 等 |
| API Base URL | API 接口地址 | https://dashscope.aliyuncs.com/compatible-mode/v1 |
| API Key | 认证密钥 | sk-xxxxxxxx |
| 系统提示词 | 定义 AI 人设 | 你是一个有 5 年经验的后端程序员... |
| 温度 | 回复创造性（0-1） | 0.7 |
| 最大 Token 数 | 单次回复长度限制 | 1000 |

### 对话设置

| 参数 | 说明 |
|------|------|
| 最大轮数 | 对话达到指定轮数后自动停止，0 表示无限制 |

## 常见问题

### Q: 点击开始没有反应？
A: 检查以下几点：
1. 是否输入了话题
2. 两个 AI 是否都配置了 API Key
3. 打开浏览器控制台查看错误信息

### Q: 对话失败，提示连接错误？
A: 检查：
1. 后端服务是否运行（http://localhost:3000）
2. API Key 是否正确
3. API Base URL 是否正确
4. 网络连接是否正常

### Q: 如何修改已配置的角色？
A: 直接在左侧面板修改对应配置即可，配置会实时保存。

### Q: 对话记录保存在哪里？
A: 对话记录保存在浏览器本地存储中，刷新页面不会丢失。导出功能可以将对话保存为 Markdown 文件。

## 开发说明

### 项目结构

```
ai-chat/
├── backend/              # Node.js 后端
│   ├── src/
│   │   ├── routes/       # API 路由
│   │   └── services/     # AI 服务
│   └── server.js
├── frontend/             # Vue3 前端
│   ├── src/
│   │   ├── components/   # Vue 组件
│   │   ├── stores/       # Pinia 状态
│   │   └── api/          # API 调用
│   └── index.html
└── docs/                 # 文档
```

### 添加新的 AI 模型

1. 在 `backend/src/services/ai.js` 中添加新的服务类
2. 在 `createAIService` 函数中注册新的提供商
3. 在前端 `AIConfig.vue` 中添加模型选项

### API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/chat/send | POST | 发送消息到 AI |
| /api/chat/test | POST | 测试 AI 连接 |
| /api/config/configs | GET/POST | 获取/保存配置 |
| /api/config/presets | GET/POST/DELETE | 预设管理 |
