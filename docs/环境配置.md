# 环境配置说明

## 后端环境变量

在 `backend/` 目录下创建 `.env` 文件：

```env
# 服务端口
PORT=3000

# 各 AI 平台的 API Key（可选）
# 如果在这里配置，前端可以直接使用
# 建议在前端界面中配置

# 通义千问（阿里云）
# ALIYUN_API_KEY=your_api_key_here

# Kimi（月之暗面）
# MOONSHOT_API_KEY=your_api_key_here

# 智谱 AI
# ZHIPU_API_KEY=your_api_key_here

# 文心一言（百度）
# BAIDU_API_KEY=your_api_key_here
```

## 前端配置

前端通过 Vite 代理连接到后端，无需额外配置。

如果需要修改后端地址，编辑 `frontend/vite.config.js`：

```javascript
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:3000',  // 修改这里
      changeOrigin: true
    }
  }
}
```

## 生产环境部署

### 1. 构建前端

```bash
cd frontend
npm run build
```

构建产物在 `frontend/dist/` 目录。

### 2. 配置后端服务静态文件

修改 `backend/server.js`，添加静态文件服务：

```javascript
import { fileURLToPath } from 'url';
import path from 'path';

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);

// 在路由配置后添加
app.use(express.static(path.join(__dirname, '../frontend/dist')));

app.get('*', (req, res) => {
  res.sendFile(path.join(__dirname, '../frontend/dist/index.html'));
});
```

### 3. 启动服务

```bash
cd backend
npm start
```

### 4. 使用 Docker（可选）

创建 `Dockerfile`：

```dockerfile
FROM node:18-alpine

WORKDIR /app

COPY package*.json ./
COPY backend/package*.json ./backend/
COPY frontend/package*.json ./frontend/

RUN npm install
RUN cd backend && npm install
RUN cd frontend && npm install

COPY . .

RUN cd frontend && npm run build

EXPOSE 3000

CMD ["npm", "start"]
```

## 故障排查

### 后端启动失败

1. 检查端口 3000 是否被占用
2. 检查 `.env` 文件格式是否正确
3. 查看控制台错误日志

### 前端无法连接后端

1. 确认后端服务已启动
2. 检查 Vite 代理配置
3. 打开浏览器开发者工具查看网络请求

### API 调用失败

1. 检查 API Key 是否正确
2. 检查 API Base URL 是否正确
3. 确认网络连接正常
4. 查看后端日志
