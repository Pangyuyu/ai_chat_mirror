# AI 对话工具 - 功能需求文档

## 1. 项目概述

### 1.1 项目名称
AI 对话工具（AI Chat Tool）

### 1.2 项目目标
创建一个图形化界面应用，允许用户配置两个不同的 AI 模型，设定话题和角色，让两个 AI 自行对话，用户可随时干预和控制对话过程。

### 1.3 技术栈
| 层级 | 技术 |
|------|------|
| 前端 | Vue 3 + Vite + Element Plus + Pinia |
| 后端 | Node.js + Express |
| HTTP 客户端 | Axios |
| 状态管理 | Pinia |
| 本地存储 | localStorage / 文件系统 |

---

## 2. 核心功能

### 2.1 话题设定
- **初始话题输入**：用户可输入对话主题或起始问题
- **话题预设模板**：提供常用话题模板（技术辩论、角色扮演、情景模拟等）
- **话题切换**：对话进行中可随时更换话题
- **话题历史**：保存使用过的话题记录

### 2.2 角色定义
每个 AI 可独立配置以下属性：

| 配置项 | 说明 | 示例 |
|--------|------|------|
| 角色名称 | AI 在对话中显示的名字 | 程序员小明、产品经理小红 |
| 角色描述/人设 | 系统提示词，定义 AI 的背景和性格 | 你是一个有 5 年经验的后端程序员... |
| 说话风格 | 可选的风格标签 | 严谨、幽默、简洁、详细 |
| 模型选择 | 选择使用的大模型 | 通义千问、Kimi、文心一言等 |
| API 配置 | API Base URL 和 API Key | 可配置本地或云端 |

### 2.3 对话控制
| 控制方式 | 说明 |
|----------|------|
| 开始 | 启动对话，两个 AI 开始轮流发言 |
| 暂停 | 暂停对话，当前状态保留 |
| 继续 | 从暂停处继续对话 |
| 停止 | 结束当前对话，保存记录 |
| 重置 | 清空当前对话，回到初始状态 |

### 2.4 用户干预
- **插入发言**：用户可随时输入内容，插入到对话流中
- **引导方向**：两个 AI 会基于用户的发言继续对话
- **编辑历史**：用户可修改之前的对话内容（可选）
- **删除消息**：用户可删除某条 AI 发言

### 2.5 停止条件
| 停止方式 | 说明 | 可配置 |
|----------|------|--------|
| 手动停止 | 用户点击停止按钮 | - |
| 轮数限制 | 达到设定轮数后自动停止 | ✓ |
| 关键词停止 | 检测到特定关键词自动停止 | ✓ |
| 超时停止 | 长时间无响应自动停止 | ✓ |

## 5. 数据流与架构

### 5.1 系统架构图
```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   用户界面    │────▶│   后端服务    │────▶│   AI API     │
│  (Vue3 前端)  │◀────│ (Node.js 后端)│◀────│ (各模型接口)  │
└──────────────┘     └──────────────┘     └──────────────┘
       │                    │
       ▼                    ▼
┌──────────────┐     ┌──────────────┐
│  本地存储     │     │   配置管理    │
│ (对话历史)    │     │  (API Keys)  │
└──────────────┘     └──────────────┘
```

### 5.2 对话流程
```
1. 用户配置两个 AI 的角色和模型
2. 用户设定初始话题
3. 用户点击【开始】
4. 后端按顺序调用 AI API：
   
   ┌─────────┐    ┌─────────┐    ┌─────────┐
   │ AI 1 发言 │───▶│ AI 2 发言 │───▶│ AI 1 发言 │───▶ ...
   └─────────┘    └─────────┘    └─────────┘
        │                │                │
        ▼                ▼                ▼
   更新 UI & 保存    更新 UI & 保存    更新 UI & 保存

5. 用户可随时：
   - 暂停：停止 API 调用，保留状态
   - 插入发言：用户消息插入对话流
   - 停止：结束对话，保存完整记录

6. 对话结束：
   - 保存到历史记录
   - 可导出为 Markdown/JSON
```

### 5.3 API 请求格式（示例）
```javascript
// 请求体
{
  model: "qwen-turbo",
  messages: [
    { role: "system", content: "你是一个程序员..." },
    { role: "user", content: "请讨论人工智能的未来" },
    { role: "assistant", content: "我认为..." },
    // ... 更多历史消息
  ],
  temperature: 0.7,
  max_tokens: 1000
}
```

## 7. 非功能需求

### 7.1 性能要求
- 首屏加载时间 < 2 秒
- API 响应延迟 < 3 秒（取决于模型）
- 对话消息渲染 < 100ms

### 7.2 安全要求
- API Key 本地加密存储
- 不上传敏感信息到服务器
- 支持环境变量配置

### 7.3 可用性要求
- 支持断线重连
- 操作有明确反馈
- 错误信息清晰易懂

### 7.4 兼容性要求
- 浏览器：Chrome、Edge、Firefox 最新版
- 系统：Windows、macOS、Linux
